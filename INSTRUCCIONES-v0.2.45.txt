EPG MrG v0.2.45 — STAR TVE
============================

Este ZIP es un overlay sobre la versión vigente v0.2.44.

APLICACIÓN
1. Abra/descomprima su repositorio EPG v0.2.44.
2. Extraiga el contenido de este ZIP en la raíz del repositorio.
3. Permita reemplazar:
   - VERSION
   - scripts/add_star_tve.py
4. Suba/commit los dos archivos al repositorio.
5. Ejecute GitHub Actions normalmente.

No es necesario editar el workflow actual: el script conserva compatibilidad
con sus validaciones, pero usa realmente la nueva prioridad 24h Canarias.

python scripts/add_star_tve.py --self-test
