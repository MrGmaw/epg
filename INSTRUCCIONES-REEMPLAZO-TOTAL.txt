INSTRUCCIONES PARA REEMPLAZAR TODO EL REPOSITORIO EPG

1. No elimine el repositorio de GitHub ni cree uno nuevo.
2. Abra la rama main del repositorio MrGmaw/epg.
3. Elimine los archivos anteriores de la rama main.
4. Descomprima este ZIP.
5. Suba EL CONTENIDO INTERNO del ZIP directamente a la raíz.
6. Compruebe que también se subió .github/workflows/actualizar-epg.yml.
7. Confirme los cambios en main.
8. Abra Actions → Actualizar EPG Ecuador y Latinoamérica.
9. Ejecute Run workflow.
10. Espere a que terminen Generar y publicar EPG y Desplegar GitHub Pages.

TVC resiliente
---------------
El workflow restaura automáticamente `epg-data/ec.xml` como caché previa.
Si la página oficial de TVC vuelve a funcionar con una estructura compatible,
se utilizará de forma automática y el respaldo no intervendrá.
